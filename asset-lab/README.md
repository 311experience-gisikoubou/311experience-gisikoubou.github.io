# AI資産形成研究所 ― 仮想投資 学習Webアプリ v0.2

## 目的
初めて株式投資を学ぶ人向けに、実資金を一切使わず、証券口座の準備・架空ETFの購入・約定・値動き・売却を実際の操作に近い流れで体験する。

## 主な機能
- 明るいホワイト系のレスポンシブな1ファイルWebアプリ（追加ライブラリ不要）
- 仮想資金100万円。架空の1口2,500円の練習ETFで買い・売り・保有を体験
- 9段階のチュートリアル。スキップ・再開・初期化（確認付き）
- ホーム、学ぶ、世界情勢、AI予測研究、取引練習、保有資産
- 画面に応じた質問候補と定型回答を示す学習アシスタント
- 自由質問をChatGPTへ持っていくための、内容確認可能な質問文コピー機能
- 質問回数・分かりづらかった件数等をブラウザ内だけに記録

## 誤解してはいけない点
- **本物の株価ではありません**。デモ用架空価格です。ニュースや株価のリアルタイム取得機能はありません。
- **アプリ内の回答は生成AIによる回答ではありません**。辞書ベースの定型解説です。より自由な相談には、自分で質問文をコピーしてChatGPTへ貼り付けます。自動送信はありません。
- 実在の証券会社や金融口座に接続しません。実際の注文は一切出ません。
- 手数料・税金・受渡日・市場価格の変動は簡略化。投資助言や損益保証はしません。
- 練習の取引履歴・仮想残高は使っているブラウザの localStorage に保存します。別端末への自動同期・バックアップはありません。初期化やブラウザデータ消去で失われる場合があります。

## 操作
`index.html` を開く → 「買い方チュートリアルを始める」 → ステップに沿って体験。右下の「✦ 相談する」をいつでも押す。

## 安全設計・公開条件
- 追加費用0円を基本とする。金融API・OpenAI APIなし。
- 外部送信処理（`fetch` 等）なし。外部サイトリンクはユーザーが押すときのみ開く。
- 操作ログは個人情報・質問文を保持せず集計だけ。外部への自動転送なし。
- GitHub Pages は **公開** なので、後から個人情報・取引実績・キーなどを同フォルダに追加しない。
- 採用デザインの方向性：Apple系の整理感・北欧の温かみ・白基調。画像モックアップを基準とする。
